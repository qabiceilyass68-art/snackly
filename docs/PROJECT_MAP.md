**قرارات معمارية مطبقة (Simplicity First):**
- 7 ملفات JS فقط، لا تجزئة، لا تجريد زائد.
- `store.js` هي الوحيدة التي تلمس localStorage.
- كل وحدة AI معزولة بـ try/catch وسجل أخطاء — التسامح مضمون.
- حالة الطلب تُخزَّن بمفاتيح إنجليزية (new/prep/ready/done/cancel) وتُعرَض بالداريجة.
- 0 اعتماديات خارجية → يعمل offline وعلى file:// مباشرة.
